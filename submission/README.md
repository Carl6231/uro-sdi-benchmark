# 投稿材料（BMC Bioinformatics）/ Submission package

这个文件夹保存 2026-11-21 的投稿用正文和 2026-11-20 的投稿信归档副本。图和附加文件的位置见下表。

## 在另一台电脑上怎么拿到这些文件

1. 用浏览器打开 https://github.com/Carl6231/uro-sdi-benchmark 即可读取公开代码、结果和图。
2. 点绿色的 **Code** 按钮，再点 **Download ZIP**，下载后解压。
3. 投稿使用已确认作者信息的正文与投稿信；六张主图和两个附加文件使用下表所列版本。

| 投稿系统里的文件类型 | 用哪个文件 |
|---|---|
| Manuscript（正文） | `submission/Manuscript.docx` |
| Cover letter（投稿信） | `submission/CoverLetter.docx` |
| Figure 1–6（正文图） | `figures/Figure1.pdf` … `figures/Figure6.pdf`（同名 `.png` 也可以） |
| Additional file 1（补充表 S1–S18） | `results/AdditionalFile1_tables.xlsx` |
| Additional file 2（补充图 S1–S12，带图注） | `results/AdditionalFile2_SupplementaryFigures.pdf` |

`submission/Manuscript.pdf` 只是方便阅读的副本，不需要上传。

## 归档副本与投稿副本

- 仓库内的正文与 AutoSubmit 的本地投稿用正文一致，已填写作者、单位、通讯邮箱和作者贡献。已署名的投稿信保存在本地投稿包中。
- 2026-11-21 的本地投稿副本使用公开 GitHub 仓库链接作为代码及结果的访问地址。

## 说明

- `Manuscript.docx` 是 2026-11-21 的投稿用正文，按 BMC 的要求排版：Times New Roman 12 号字、双倍行距、连续行号、页码。
- 摘要 350 词（BMC 上限）；参考文献 75 篇，每一篇都对照 Crossref、PubMed、DataCite、arXiv 或出版方页面核对过，能查到 DOI 的都附上了。
- 方法部分的 "Use of large language models" 一节是出版社 Springer Nature 的要求，请保留。
