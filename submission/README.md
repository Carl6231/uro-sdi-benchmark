# 投稿材料（BMC Bioinformatics）/ Submission package

这个文件夹里是投稿要用的文字材料。图和附加文件在仓库的其他文件夹里，下表写明了每个文件的位置。

## 在另一台电脑上怎么拿到这些文件

1. 用浏览器打开 https://github.com/Carl6231/uro-sdi-benchmark ，并登录你的 GitHub 账号（仓库目前是私有的，不登录看不到）。
2. 点绿色的 **Code** 按钮，再点 **Download ZIP**，下载后解压。
3. 投稿时按下表把文件传到投稿系统里。

| 投稿系统里的文件类型 | 用哪个文件 |
|---|---|
| Manuscript（正文） | `submission/Manuscript.docx` |
| Cover letter（投稿信） | `submission/CoverLetter.docx` |
| Figure 1–6（正文图） | `figures/Figure1.pdf` … `figures/Figure6.pdf`（同名 `.png` 也可以） |
| Additional file 1（补充表 S1–S18） | `results/AdditionalFile1_tables.xlsx` |
| Additional file 2（补充图 S1–S12，带图注） | `results/AdditionalFile2_SupplementaryFigures.pdf` |

`submission/Manuscript.pdf` 只是方便阅读的副本，不需要上传。

## 投稿前还要你自己填的地方

- `Manuscript.docx` 第一页：作者姓名、单位、通讯作者邮箱（方括号里的占位文字）。
- `Manuscript.docx` 的 Declarations 部分：Authors' contributions（作者分工）。
- `CoverLetter.docx` 末尾：通讯作者署名、单位、邮箱；可选填推荐审稿人。
- 把这个 GitHub 仓库设为公开，并在 Zenodo 存档拿到 DOI，替换 Availability of data and materials 里的 `[DOI to be added]`。

## 说明

- `Manuscript.docx` 是 2026-11-20 的定稿，按 BMC 的要求排版：Times New Roman 12 号字、双倍行距、连续行号、页码。
- 摘要 350 词（BMC 上限）；参考文献 75 篇，每一篇都对照 Crossref、PubMed、DataCite、arXiv 或出版方页面核对过，能查到 DOI 的都附上了。
- 方法部分的 "Use of large language models" 一节是出版社 Springer Nature 的要求，请保留。
- 在线可编辑版本（Claude 文档）：正文 https://claude.ai/artifact/9BxEnhNSfHETD484tENs1f ，投稿信 https://claude.ai/artifact/U5fGYaRDh7JLLtRa1NY6q8 。
