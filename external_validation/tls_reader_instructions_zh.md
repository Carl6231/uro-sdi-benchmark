# 肾肿瘤 H&E 切片独立阅片说明

本次阅片要确定切片中可辨识的三级淋巴结构（TLS）及其周围组织。包内有三张全分辨率 OME-TIFF，均使用新的切片编号。请分别完成自己的第一轮判读，封存导出文件后再安排联合复核。

## 在 QuPath 中阅片

1. 在你自己的本地 QuPath 项目中打开三张 OME-TIFF，将图像类型设为 Brightfield H&E。按切片编号从小到大完成全片系统扫描。只有阅片者自己的标注可参与第一轮判读。
2. 每张切片先勾画一个或多个已完整检查的可判组织范围，类型设为 `ReviewArea`。排除玻片背景。折叠、失焦、破损以及无法判断的区域另画 `Uncertain`。如未能完成全片，请在回执记录覆盖范围，未审核部分留空。
3. 在已检查范围内，每个可辨识的 TLS 单独绘制一个闭合多边形，类型设为 `TLS`。保留实际轮廓、分叶和相邻独立结构。在高倍下重点看淋巴细胞是否形成有组织的聚集、是否可见滤泡样结构及周围组织关系。早期、微小或边界模糊的聚集若无法与普通浸润区分，可标 `Uncertain`。H&E 无法确认的成熟度可留空。
4. 把可确定的普通淋巴细胞浸润标为 `Infiltrate`，肿瘤、间质和可辨识的正常组织分别标为 `Tumour`、`Stroma`、`Normal`。每个 TLS 外围也请连续勾画一圈可确定的相邻组织，尽可能延伸至约 200 µm。组织相互混杂时保留不确定区域。除按全片系统扫描外，也请记录无 TLS 的组织区。
5. 在 QuPath 的对象导出菜单中将全部 annotation polygons 导出为 GeoJSON，保留对象分类与几何，使用图像的原始像素坐标。三张图分别以图像编号命名，例如 `Slide_01.geojson`。不需要导出缩略图坐标或手工换算微米。

## 交回材料

交回自己的三个 GeoJSON，并在回执中注明读者代码（A 或 B）、各切片是否完整判读、未判区域及其原因。若在已审核区域内未发现明确 TLS，仍请导出 `ReviewArea` 并在回执注明。第一轮交回后再对读者间意见分歧进行复核，保留两个原始版本和单独的共识版本。
